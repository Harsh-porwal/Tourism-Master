# 🌍 Tourism-Master

### AI-Powered Smart Travel Planner

**Tourism-Master** is an AI-based travel planning web application developed for a hackathon. The system generates personalized travel itineraries based on user preferences such as destination, number of travel days, travel mode, and interests.

The application integrates the **Gemini API** to intelligently process user inputs and generate a structured, easy-to-follow travel plan.

## 🚀 Problem Statement

Planning a trip can be time-consuming and overwhelming. Travelers often struggle with:

* Deciding where to stay
* Finding good restaurants
* Choosing places to visit
* Organizing day-wise schedules

Tourism-Master solves this problem by automating itinerary generation using AI.

---

## 💡 Our Solution

Users simply enter:

* 📍 Current Location
* 🗺️ Destination
* 📅 Number of Travel Days
* 🚗 Mode of Travel
* 🎯 Interests (Adventure, Food, Culture, Relaxation, etc.)

After clicking **Generate Planner**, the system:

1. Sends the data to the backend.
2. Uses the Gemini API for intelligent processing.
3. Returns a detailed and user-friendly itinerary.

## 🚀 How It Works

1. User enters:

   * Current location
   * Destination
   * Number of travel days
   * Mode of transportation
   * Interests

2. User clicks **Generate Planner**.

3. The application:

   * Sends user input to the backend.
   * Backend calls the Gemini API.
   * Gemini processes the data.
   * Returns a structured and easy-to-read travel itinerary.

4. The generated plan includes:

   * 🏨 Hotel suggestions
   * 🍴 Restaurant recommendations
   * 🗺️ Tourist attractions
   * 💡 Travel tips
   * 📅 Day-wise planning
